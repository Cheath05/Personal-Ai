Cardinal Privacy Policy

Last updated 27 September 2026 (school files)

Cardinal is a personal assistant I built for my own accounts. I'm its only user, and it isn't offered to the public. It runs on my own server and can only be reached from my own devices.

What Cardinal reads

  • Google Calendar: reads my calendars to show my schedule and write a morning briefing. The only calendar it changes is a separate "Cardinal" calendar that it creates itself, with items I add or confirm.
  • Gmail (read-only): the number of unread messages, and the sender and subject of recent unread messages. Message bodies are not read.
  • Blackboard: due dates from my course calendar feed.
  • School files I add: slides, readings and notes I upload myself, to search them and make study notes and flashcards.

How it's used

This data is only used to show me my day and to let my assistant answer questions about it. It is processed by AI models running on my own computers. It is not sold, not used for advertising, and not shared with anyone.

Where it's stored

Sign-in tokens are encrypted and stored on my server. Calendar and email details are held in memory for a few minutes and not stored as such. The daily briefing, my conversations with the assistant, and the school files I upload are saved on that server and nowhere else.

Google API data

Cardinal's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Cardinal's Today view, or at myaccount.google.com/permissions. Contact: w.alexbenton@gmail.com.
